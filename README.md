# Sam Comic App

Sam Comic App 是一個 Android OPDS 漫畫閱讀器，可以讀取 OPDS 書庫，下載單一本漫畫到暫存資料夾，並直接在 app 內閱讀。

目前版本：`0.7`

## 功能

- 讀取 OPDS/Atom feed 目錄。
- 支援帳號與密碼欄位，成功取得目錄後會記住上次可用的網址、帳號與密碼。
- 支援 OPDS 子目錄導覽、返回、上一頁與下一頁目錄連結。
- 支援 OPDS 搜尋連結與 OpenSearch 描述檔，可在提供搜尋功能的書庫中搜尋書本。
- 支援 OPDS 分頁資訊顯示，若書庫提供總筆數與每頁筆數會顯示目前頁數。
- 取得目錄後可隱藏輸入欄，目錄頁會保留書庫名稱與導覽列。
- 目錄切換後會自動捲到頂部。
- 目錄可用觸控拖動，也可用滑鼠滾輪捲動。
- 目錄右側會顯示捲軸。
- 支援下載與閱讀 `CBZ`、`ZIP`、`PDF`、`EPUB`。
- 下載時會顯示進度條。
- 下載會先寫入暫存檔，完成後才替換為正式檔，避免中斷下載留下損毀檔案。
- 一次只處理單本檔案，下載檔案會放在 app cache 暫存資料夾。
- 可從外部程式用「開啟」或「分享」呼叫 app 開啟 `CBZ`、`ZIP`、`PDF`、`EPUB` 檔案。
- 支援從 OPDS 目錄自動開啟上一本文或下一本文。
- 閱讀進度會依書庫與書本記錄在本機。
- 目錄項目會顯示已記錄的閱讀頁數進度。
- 閱讀頁支援點擊左側上一頁、右側下一頁。
- 閱讀頁支援音量鍵翻頁，音量增加為下一頁，音量減少為上一頁。
- 閱讀頁採九宮格點擊區域：
  - `1/2/4/7`：上一頁
  - `3/6/8/9`：下一頁
  - `5`：顯示或隱藏頂部工具列
- 閱讀頁第一頁按上一頁時，會回到原目錄找上一本並恢復該書上次閱讀頁。
- 閱讀頁最後一頁按下一頁時，會回到原目錄找下一本並顯示下載進度。
- 閱讀頁右上角顯示頁碼，可點擊開啟跳頁彈窗。
- 隱藏頂部工具列時，頁碼仍會顯示在右上角並可點擊跳頁。
- 橫向閱讀時會隱藏系統狀態列。
- 橫向閱讀時會以雙頁模式顯示，兩頁靠中間併攏；沒有右頁時右半邊保持黑色背景。
- 橫向雙頁模式翻頁時會一次翻兩頁。
- 橫向雙頁模式可單獨前進一頁，用於避開封面造成的對開錯位。
- 橫向雙頁模式可切換左右頁顯示順序，例如 `1-2` 與 `2-1`。
- 支援裝置方向變動自動轉向。
- 自訂 app 圖示，以灰色線條呈現 OPDS 下載漫畫的意象。

## 支援格式

- `CBZ`
- `ZIP`
- `PDF`
- `EPUB`

`CBZ`、`ZIP`、`EPUB` 會從壓縮檔中抽出圖片頁面閱讀；`PDF` 會使用 Android `PdfRenderer` 顯示。

## 開發

此專案使用 Kotlin、Jetpack Compose 與 Android Gradle Plugin。

常用建置指令：

```powershell
.\gradlew.bat :app:assembleDebug
```
